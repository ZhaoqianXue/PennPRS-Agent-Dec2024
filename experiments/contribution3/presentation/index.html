Cross-Trait Transfer

Bundles → evidence → one chosen model; evaluate on the full benchmark row.

  1. 1STEP

    Prepare assets

    • PurposeDefine the global trait-bundle catalog and build a large, target-specific candidate list.
    • Rough scale~660 trait bundles in the global index; roughly hundreds of candidate trait bundles per target.
  2. 2STEP

    Scout

    • PurposeChoose which bundles get deep evidence gathering next.
    • Tools
    • Rough scale~50–60 trait bundles from the per-target pool.
  3. 3STEP

    Gather

    • PurposeFill a structured evidence ledger for the probe bundles.
    • Tools
    • Rough scale~50–60 trait bundles (same probe set as Scout).
  4. 4STEP

    Judge

    • PurposeRank supporting bundles and decide how many feed the model picker.
    • Tools
    • Rough scale~5–10 supporting trait bundles.
  5. 5STEP

    Genetic correlation batch

    • PurposeAdd cross-trait relatedness estimates for the shortlist to help later disambiguation.
    • Tools
    • Rough scale~5–10 trait bundles (shortlist, same as Judge).
  6. 6STEP

    Pick (+ global primary)

    • PurposeHydrate scoring models inside each supporting bundle and pick one primary recommendation across bundles.
    • Tools
    • Rough scalePer trait bundle: up to ~18 PGS models fully examined, ~5 frontier PGS models; one primary PGS model after cross-bundle merge.
