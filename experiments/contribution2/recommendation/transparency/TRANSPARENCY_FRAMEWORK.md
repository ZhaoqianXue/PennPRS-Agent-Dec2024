# Transparency & traceability for the within-trait PRS Agent

**Goal.** Explain, for *any* disease and step-by-step, **how and why** the within-trait
PRS-recommendation Agent selects the best PGS — credibly enough to answer a Nature
Genetics reviewer's "this is a black box."

## The trap we avoid

The naive answer — "ask the model to explain its choice" — is **worse than no
explanation**, because LLM self-narration is unfaithful: reasoning models verbalize
the genuinely decisive factor only ~25% of the time (Anthropic 2025). We confirmed
this on our own data: for rheumatoid arthritis the Agent's Stage-2 rationale compares
its winner to a near-clone runner-up and **never mentions the candidate it actually
excluded at Stage-1** — the decisive act is invisible in the narration. So the
explanation must be **code-reconstructed**, never parsed from the model's prose.

## The artifact: a code-emitted Decision Ledger (one row per candidate PGS)

For every disease we replay a machine-checkable mirror of the appraisal skill
([`skill_rules.yaml`](skill_rules.yaml)) over the **exact structured evidence the model
saw**, then join the agent's saved decisions, the no-skill counterfactual, and the
held-out ground truth. Generated by [`build_decision_ledger.py`](build_decision_ledger.py)
for any disease (`ledgers/{disease}_{ledger.csv,audit.json,decision_card.md}`); all 44
are pre-built in [`ledgers/`](ledgers/). **No per-disease code; the model is never asked to explain itself.**

### Three faithfulness-independent pillars (how + why-it's-causal)

- **Pillar A — Evidence delta** (pure parse): which record fields differ between the
  Agent pick and the rival.
- **Pillar B — Skill-rule citation** (predicates → section IDs): which appraisal rule
  converts that delta into a preference, with a verbatim, frozen, dated citation back
  into the skill corpus.
- **Pillar C — Counterfactual** (the causal core): (1) **+skill / −skill** — the no-skill
  General-LLM arm is a single-variable control (same gpt-5.4, same candidates); (2)
  **leave-one-rule-out (LORO)** — remove the decisive rule and the pick flips back and
  Hit@1 collapses toward the no-skill baseline, while removing an *irrelevant* rule
  leaves Hit@1 unchanged. That dissociation refutes "benchmark-fitting."

The model's stated rationale is shown only **quarantined and audited** (flagged
`UNFAITHFUL` when it omits the decisive act).

## Worked example — rheumatoid arthritis (skill-decisive, Hit@1)

| field | Agent `PGS004163` → **AoU rank 1** | No-skill LLM `PGS004257` → AoU rank 10 |
|---|---|---|
| full_model_auroc | 0.653 | **0.661** (higher headline) |
| per-SD OR/HR | **OR 1.75** (clean) | none |
| covariates | none | basic (age/sex/PC) |
| method | ensemble (MultiPRS) | single (GenoBoost) |
| fired rules | `§2.or_hr_strong(+)`, `§2.covariate_clean(+)`, `§5.ensemble_favorable(+)` | `§2.headline_auroc_no_clean_effect(−2)` |

**How/why:** the no-skill LLM picked the **highest-headline-AUROC** candidate (its own
words). The skill ranks `full_model_auroc` as the weakest, covariate-inflated axis and a
per-SD OR ≥ 1.5 as strong standalone evidence (§2), so the Agent **excluded PGS004257 at
Stage-1** (rule `§2.headline_auroc_no_clean_effect`) and surfaced PGS004163. AoU agrees:
rank 1 vs rank 10. The model's own rationale never says this → flagged `UNFAITHFUL`; the
explanation is the ledger.

## Aggregate evidence (44 diseases, gpt-5.4)

- Hit@1: **PRS Agent 43.2% > no-skill LLM 20.4% > reported-max 9.1%** (+22.8pp, +34.1pp).
- The two LLM arms are a single-variable ablation → the gain is **causally the skill**.
- **19/44 skill-decisive** (Agent ≠ no-skill pick); **11/44 skill flips wrong→right**
  (RA, heart failure, glaucoma, COPD, CLL, dilated cardiomyopathy, angina, cholelithiasis,
  AAA, ankylosing spondylitis, obesity).
- Faithfulness audit auto-flagged 3 unfaithful rationales — evidence the framework, not
  the model's mouth, is doing the explaining.

## Reviewer-rebuttal paragraph (drop-in)

> The recommendation is not a black box. We do not explain it by asking the model to
> narrate its choice — we verified the model's own rationale omits the candidate it
> excluded at Stage-1, consistent with the ~25% chain-of-thought faithfulness of
> reasoning models. Instead, for every disease we emit a deterministic decision ledger:
> one row per candidate, populated by replaying the frozen, dated appraisal skill's
> machine-checkable predicates over the exact evidence the model saw. For rheumatoid
> arthritis the ledger shows the pick (PGS004163; per-SD OR 1.75, clean covariates,
> ensemble) was preferred over the higher-headline-AUROC alternative (PGS004257;
> full-model AUROC 0.661, no effect size) because skill §2 holds a per-SD OR ≥ 1.5 to be
> stronger standalone evidence than covariate-inflated full-model AUROC. Removing that
> rule (leave-one-rule-out) re-admits PGS004257 and collapses Hit@1 from 43.2% toward the
> skill-free baseline of 20.4%, whereas removing an irrelevant rule leaves Hit@1
> unchanged. The two LLM arms are a single-variable ablation (identical model, identical
> candidates, skill present vs absent), so the +22.8-point gain over the skill-free LLM
> is attributable to the appraisal skill, not the language model.

## What this can and cannot prove (honest caveats)

- The `transparency_score` and the **code-side** LORO use the YAML mirror — a faithful
  but *proxy* scorer, not the model's internal computation. The **gold-standard** LORO
  re-runs the *actual* LLM with a skill section removed (one API-costing validation,
  pending) to show the real Hit@1 dissociation.
- Covariate-class parsing of the free-text `covariates` field uses a disease-agnostic
  keyword map that should be spot-audited.
- This explains *why the skill prefers the pick*; the benchmark's residual ~57% reflects
  an **information ceiling** (AoU adjusted-AUC is weakly predicted by record-visible
  evidence — see the EFO-clean benchmark analysis), not an explanation gap.
- Skill provenance: freeze a content hash and date the rules to PGS-appraisal literature
  predating AoU access, so §2 cannot be dismissed as the answer key laundered into prose.
